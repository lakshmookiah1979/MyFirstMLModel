# MyFirstMLModel

Learning of Real-World End-to-End ML Deployment Workflow

## a. Problem Statement

Breast cancer is one of the most common cancers, and early, accurate diagnosis
significantly improves treatment outcomes. This project builds and compares
multiple machine learning classification models that predict whether a breast
tumor is **malignant** or **benign** based on features computed from digitized
images of a breast mass. The goal is to identify which model performs best on
this dataset and deploy the best-performing model as an interactive web app
using Streamlit, so predictions can be made from user-provided input in
real time.

## b. Dataset Description

The project uses the **Breast Cancer Wisconsin (Diagnostic) dataset**, available
built-in through `sklearn.datasets.load_breast_cancer`.

| Property | Details |
|---|---|
| Samples | 569 |
| Features | 30 numeric features (e.g. mean radius, mean texture, mean perimeter, mean area, mean smoothness, etc.) |
| Target classes | 2 — Malignant (212 samples) and Benign (357 samples) |
| Missing values | None |
| Feature type | Real-valued measurements computed from digitized images of fine needle aspirate (FNA) of breast masses |

The dataset was split into **80% training** and **20% testing** data
(stratified by class) to evaluate model performance. Features were scaled
using `StandardScaler` before training. A copy of the dataset used is saved
as `test_data.csv` in this repository.

## d. Models Used

Six classification models were trained and evaluated on the same
train/test split for a fair comparison.

### Comparison Table

| Model | Accuracy | AUC Score | Precision | Recall | F1 Score | MCC Score |
|---|---|---|---|---|---|---|
| Logistic Regression | 0.9825 | 0.9954 | 0.9861 | 0.9861 | 0.9861 | 0.9623 |
| Decision Tree Classifier | 0.9123 | 0.9157 | 0.9559 | 0.9028 | 0.9286 | 0.8174 |
| K-Nearest Neighbour | 0.9561 | 0.9788 | 0.9589 | 0.9722 | 0.9655 | 0.9054 |
| Naive Bayes (Gaussian) | 0.9298 | 0.9868 | 0.9444 | 0.9444 | 0.9444 | 0.8492 |
| Random Forest (Ensemble 1) | 0.9561 | 0.9939 | 0.9589 | 0.9722 | 0.9655 | 0.9054 |
| Gradient Boosting (Ensemble 2) | 0.9561 | 0.9907 | 0.9467 | 0.9861 | 0.9660 | 0.9058 |

*(Metrics generated by running `train_models.py`; see `model/model_comparison.csv` for the raw output.)*

### Observations

- **Logistic Regression is the strongest overall performer**, leading on
  Accuracy (0.9825), AUC (0.9954), and MCC (0.9623). After scaling, the
  dataset's classes are close to linearly separable, which plays directly to
  Logistic Regression's strength as a linear classifier.
- **Gradient Boosting achieved the best Recall (0.9861)** and the best F1
  Score (0.9660) among the ensemble/tree-based models, and even matched
  Random Forest and KNN on accuracy. Its boosting approach — sequentially
  correcting errors from prior trees — helped it catch nearly all malignant
  cases, which is valuable in a medical screening context.
- **Random Forest and KNN tied on Accuracy, Precision, Recall, and F1**
  (0.9561 / 0.9589 / 0.9722 / 0.9655), but Random Forest edged ahead on AUC
  (0.9939 vs 0.9788), meaning it separates the two classes more confidently
  across different decision thresholds, not just at the default 0.5 cutoff.
- **Naive Bayes had a surprisingly high AUC (0.9868)** despite middling
  Accuracy (0.9298) and the lowest MCC among non-tree models (0.8492). This
  suggests its predicted probabilities rank cases well, but its independence
  assumption (features like mean radius, mean perimeter, and mean area are
  highly correlated) hurts it at the hard classification boundary.
- **Decision Tree Classifier was the weakest model** across every metric
  (Accuracy 0.9123, AUC 0.9157, MCC 0.8174) and had the lowest Recall
  (0.9028), meaning it missed more actual malignant cases than any other
  model. A single unpruned tree overfits the training split and generalizes
  worse than the ensemble methods (Random Forest, Gradient Boosting) built
  on top of many trees.
- **Overall**, for a cancer-diagnosis task where **missing a malignant case
  (false negative) is the costliest error**, Gradient Boosting's high Recall
  combined with Logistic Regression's high AUC/MCC make them the two
  strongest candidates for deployment. The Streamlit app allows switching
  between all six models to compare predictions interactively.

## How to Run Locally

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Train all models (creates test_data.csv and populates model/)
python train_models.py

# 3. Launch the Streamlit app
streamlit run streamlit_app.py
```
